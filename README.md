# Image Processing Homework

Python assignments from the Image Processing course at Tongji University.

| Assignment | Topic |
| --- | --- |
| [HW1](HW1-FilterPractice/) | Ideal, Gaussian, and Butterworth frequency-domain filters |
| [HW2](HW2-EqualizeHist/) | Histogram equalization in YUV, HSV, and grayscale |
| [HW3](HW3-SpecifyHist/) | Histogram specification using a reference image |
| [HW4](HW4-Logic%26Filter%26Edge/) | Binary logic, spatial filtering, and edge detection |
| [ImageNetResizeHist](ImageNetResizeHist/) | Batch resizing, histogram enhancement, and evaluation |

## Setup

```bash
python -m pip install -r requirements.txt
cd HW1-FilterPractice
python main.py
```

Run each HW1–HW4 demo from its assignment directory. ImageNetResizeHist has its own requirements and dataset instructions. Supply your own images at the paths listed in each README. Matplotlib displays the results in desktop windows.
